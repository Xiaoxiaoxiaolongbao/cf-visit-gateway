# 全国「奶蛙 / 奶龙大学」类站点风格调研

> 调研对象：全网「奶蛙大学 / 奶龙大学」系列仿冒学校域名及其站点的视觉风格与技术形态
> 数据源：[drysaltyfish/all-of-milkdragons](https://github.com/drysaltyfish/all-of-milkdragons) 的 `result.json`（由该仓库 GitHub Actions 每日 DNS 探测 + HTTP 跳转追踪自动抓取）
> 本次分析口径：数据集 242 条；另抽样 17 个 HTTP 200 页面做配色/字体/文案的定性核验
> 抓取日期：2026-10-17

---

## 一、摘要

1. 这个梗的核心不是「做一个假学校」，而是**用一个假校名域名把访客送到一所真实的大学官网**：数据集里 **80.2%（194/242）** 的最终落点是真实 `.edu.cn` 域名，覆盖 **155 所**不同高校。
2. 站点形态只有三种，比例高度集中：**延迟跳转页 41.7%**、**服务端直跳 33.1%**、**有实际内容的站点 25.2%**。真正做完整「仿官网」的是少数。
3. 视觉上高度同质化，几乎全部围绕「奶」这个字做文章：**暖奶油 / 琥珀黄**出现次数最多（17 次），其次是**深色底**（16 次）和**近白底**（15 次）；全样本里**冷色（蓝）只出现 2 次**——没有任何一个站点走科技风/紫青渐变。
4. 最有效的两个「像真的」装置是：**镜像真实校徽（79.8% 的域名抓到了目标学校的 logo）** 和 **直接挪用目标学校的校训**（如东华大学「崇德博学 · 砺志尚实」被原样使用）。
5. 工程质量普遍粗糙：**23.1% 的域名有抓取错误、21.1% 长期处于掉线状态**、延迟中位数 3.5 秒、最大 180 秒；样本中还出现自签证书与证书域名不匹配。

## 三、机制：三种形态

| 形态 | 占比 | 数量 | 实现特征 | 实测证据 |
| --- | --- | --- | --- | --- |
| 延迟跳转页 | 41.7% | 101 | 页面先呈现自己的内容，再用 JS/`meta refresh` 延时跳走 | 观测到 `setTimeout(..., 120/500/1020)`、`http-equiv=refresh`、倒计时文案「5 秒后自动跳转」 |
| 服务端直跳 | 33.1% | 80 | 返回 301/302 空 body，什么都不展示 | 抽样 4 例均为 `301/302 + 0 KB body` |
| 内容站 | 25.2% | 61 | 真的做了一个页面（校内网/仿官网），不跳或手动跳 | `宇宙奶蛙大学.online`、`皇家奶龙大学.com`、`中国奶龙大学.fun` 等 |

跳转链形态（首跳状态:跳数）：`200:1跳` 80、`301:1跳` 48、`302:1跳` 25、`301:2跳` 11、`301:3跳` 4、`200:2跳` 6、无跳转 32。**绝大多数是一跳到底**，多跳主要来自「裸域 → www → 目标站」。

## 四、最终落点：真实高校

- **80.2%（194/242）** 最终停在 `.edu.cn` 或 `.edu` 域名上，**去重后 155 所**高校。
- 出现次数最多的目标：`swu.edu.cn`（西南大学）5、`bit.edu.cn`（北京理工）5、`sjtu.edu.cn`（上海交大）4、`suda.edu.cn`（苏州大学）4、`neu.edu.cn`（东北大学）3、`lnu.edu.cn` 3、`gdut.edu.cn` 3。
- 覆盖范围从 985（北大医学部、上海交大、同济、吉大、大连理工）到地方院校（湖州师范、重庆移通学院、大连东软信息学院），**没有明显的层次偏好**——说明分配逻辑是随性的（谁先被撞上就指谁），而不是刻意挑名校。
- 还有 3 条落在 `dnspod.qcloud.com`（域名未解析的默认页），4 条被标记 `blocked`（访问被阻断）。

## 五、视觉风格

### 5.1 配色：暖奶油 / 琥珀为主，冷色几乎绝迹

按每个样本出现次数最多的颜色归类（17 个 200 页面）：

| 主色类别 | 样本数 | 占比 |
| --- | --- | --- |
| 白 / 近白（`#ffffff`、`#fffdf7`、`#fdfaf3`） | 6 | 42.9% |
| 奶油 / 琥珀（`#f2e0a8`、`#fde68a`、`#ffd23f`、`#fece0e`） | 4 | 28.6% |
| 深色底（`#000000`、`#142638`、`#3a2c00`） | 4 | 28.6% |

全样本颜色出现次数：**奶油/琥珀 17 > 深色 16 > 近白 15 > 其它暖色 4 > 红/砖红 3 > 蓝/冷色 2**。

结论：配色几乎完全被「奶」的意象绑定——**米白纸感 + 琥珀黄主色 + 棕色文字**是最常见的三件套；另一支走**纯黑/深棕底 + 亮黄点缀**。红砖色偶见于模仿国内高校官网的红色主视觉（如 `#c0392b` + 白）。

### 5.2 字体与排版

- 几乎全部使用**系统字体栈**，未引入网络字体：正文实测到 `-apple-system, BlinkMacSystemFont, ...` 与 `font-family: inherit`。
- 校名一律**中英对照**（「中国奶龙大学 / China Nailong University」「ROYAL NAILONG UNIVERSITY」），英文名多按拼音或意译硬造（Cosmic Milkfrog University）。
- 标题字号大、行距紧，副标位置固定放**校训式口号**（见 5.4）。

### 5.3 招牌元素

| 元素 | 覆盖率 / 证据 |
| --- | --- |
| **借用真实校徽** | 193/242（**79.8%**）的域名抓到了目标学校的 `logo_url`，192 条本地镜像了校徽文件 |
| **校训挪用** | 东华大学「崇德博学 · 砺志尚实」原样使用；湖州师范「明体达用」原样使用；中国农大「解民生之多艰，育天下之英才」被改成「解民生之多**奶**，育天下之英**龙**」 |
| **校区列表** | 「凌水校区 / 开发区校区 / 盘锦校区」直接搬运大连理工的真实校区名，制造「这是一所多校区大学」的错觉 |
| **伪业务组件** | 教务系统、校长信箱、招生信息、图书馆、一卡通、学工；`宇宙奶蛙大学.online` 还做了「新生报到通道」「校长信箱：校长@宇宙奶蛙大学.online」 |
| **伪实时数据** | 「今日奶泡浓度：加载中」「荷叶承重上限：1 只（含书包……）」「宇宙历 138 亿 年」 |
| **免责声明** | 部分站点主动标注「非官方粉丝站点 · 与湖州师范大学无官方关联」 |

### 5.4 文案模板（真实引文）

跳转页的措辞已经高度模板化，常见五段式：

1. **护送叙事**：「奶龙正在护送你前往 中国奶龙大学」「正在前往中国奶龙大学官网」
2. **倒计时承诺**：「5 秒后自动跳转」「即将跳转至 dhu.edu.cn」「5 SEC」
3. **主按钮**：「立即前往 ↗」「立即前往官网 ↗」「跳过动画，直接前往 →」
4. **兜底提示**：「若未自动跳转，请点击『立即前往』」
5. **反悔钩子**：「等等！让我再玩会儿奶龙」（点击后取消跳转，把控制权交回访客）

还有一类「伪流程」写法，把跳转包装成正经手续：「正在校验录取通知书…」「脑子正在连接」「东华大学官网响应有点慢… 重新打开」。

### 5.5 版式骨架

- **跳转中页**：单屏居中 → 校徽/圆盘主体 → 中英文校名 → 校训 → 倒计时 → 主按钮 → 免责声明。体量 5–30 KB，纯静态。
- **内容站（仿官网）**：完整 IA，`皇家奶龙大学.com` 的导航是「认识奶大 / 学习与招生 / 研究与创新 / 校园生活 / 新闻与发现」，与港校/国内高校官网的信息架构高度一致；顶部还有「在校生 / 校友与伙伴 / 访客」身份分流，标准的大学官网套路。

## 六、命名与域名策略

| 维度 | 分布 |
| --- | --- |
| 词根 | 奶龙 176（72.7%）、奶蛙 65（26.9%）；大学 241（99.6%） |
| 地域前缀 | 无地域 108、中国 11、北京 8、江苏 7、浙江 7、南京 7、上海 6、广东 6、西南 6、东北 5、天津 4、山东 4、河南 4、湖南 4、四川 4 |
| 后缀 | `.com` 97、`.cn` 37、`.top` 28、`.icu` 25、`.site` 12、`.fun` 10、`.online` 6、`.org` 6、`.work` 5、`.vip` 4、`.net` 3、`.space` 3、`.tech` 3、`.xyz` 1 |

规律：**「奶龙 → 奶蛙」是二创分流**（奶蛙是奶龙的民间变体，所以带「奶蛙」的更像是二次创作）；**便宜后缀占多数**（top/icu/site/fun/online 合计 81 个，占 33.5%），`.com/.cn` 占 55.4%；地域前缀以高校密集城市为主（北京、南京、上海、浙江、江苏），一个域名可注册多个后缀形成「多校区」矩阵（如 `中国奶龙大学` 同时持有 `.com/.net/.org/.icu/.fun/.top/.vip/.xyz`）。

数据集只覆盖「大学」，而**中学类的数量确实更少**，且更偏向手工整活，已知个案：

## 十、附录：字段与复现

`result.json` 关键字段：`domain`（原始域名，含 IDN）、`ascii`（punycode）、`final_url`（跳转终点）、`title`、`logo_url` / `logo_path`（目标校徽）、`jump_type`（`direct`/`delayed`/`none`）、`redirect_chain`（`状态:URL -> …`）、`first_status` / `final_status`、`blocked`、`latency_s`、`down_since`、`last_ok`。

复现本文数据的两步：

```bash
# 1. 取数据集（公开仓库，无需鉴权）
curl -sL https://raw.githubusercontent.com/drysaltyfish/all-of-milkdragons/main/result.json -o result.json

# 2. 统计口径：按 jump_type 分组、按 final_url 归并目标院校、按 final_status 统计可达性
```

> 说明：本文所有比例均由上述字段直接计算，风格结论来自对 17 个返回 200 页面的 HTML 采样（颜色词频、字体声明、跳转实现、版式词），非主观印象；采样页面清单与原始特征保存在 `.toolchains/sample-analysis.json` 与 `style-evidence.json`（不随仓库发布）。
